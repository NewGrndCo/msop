# Monsta Squeeze OPOS

Monsta Squeeze Operations OS — a responsive V0 proof-of-concept production workflow simulator.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This V0 is a frontend-only demonstration. It uses seeded mock data and localStorage persistence; it does not connect to production hardware, sensors, PLCs, databases, authentication, or real AI services.
